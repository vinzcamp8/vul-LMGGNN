# Thesis Project README

This project contains two additional README files that provide all the necessary configurations:

1. **README_vulmgnn.md**: Contains details from the original repositories which this repo was forked by.
2. **README_extra.md**: Provides configuration instructions written by me (Vincenzo Campagnano) during my thesis work.

Please refer to these files for comprehensive setup guidelines.

**Install Dependencies**: Ensure you have all the required dependencies installed. You can do this by running:
```sh
pip install -r requirements.txt
```

## Main scripts
Inside each file are defined the arguments to pass and an example of command run.
- run.py: to run vul-lmgnn
- baseline_run.py: to run all other models
- demo.py: to test the model on a single file
- demo_gui.py: easy-to-use web app GUI to test the model using demo.py
